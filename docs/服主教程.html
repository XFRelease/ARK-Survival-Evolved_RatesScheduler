第一章 · 软件总览

软件总览

倍率调整器（RatesScheduler）是方舟生存进化服务端插件：按你排好的时间表，到点自动开启全服倍率活动、到点自动还原倍率，全程自动通知玩家。所有行为都由一个 JSON 配置文件控制。

⏰

定时倍率调度

到点自动开活动、到点自动收，全程无需人工值守。

📅

按星期排程

周一至周日各配各的时间与倍率，另有 "*" 通配兜底。

🎯

16 项倍率乘算

经验、驯服、采集、孵化、留痕等 16 项倍率精确控制。

📢

全服通知与预告

屏幕大字 + 聊天彩色广播，可提前预告、结束前提醒。

🖼️

MOTD 自动切换

活动期自动换活动 MOTD，结束后换回常规 MOTD。

💬

玩家自助查询

玩家输入 /今日倍率 即可查看今日活动时间与倍率明细。

🎛️

服主手动接管

/开启倍率、/重置倍率 随时手动开收，不受时间表限制。

🔄

配置热重载

改完配置输入一条 Reload 命令即时生效，无需重启服务器。

第二章 · 环境要求

环境要求

项目要求
操作系统Windows（方舟生存进化服务端为 Windows x64）
服务端框架Ark Server API（ArkApi），最低版本 3.5
运行库VC++ 2015-2019 运行库 x64（含 MSVCP140 / VCRUNTIME140，即 Visual C++ Redistributable）；Windows 10 及以上系统自带 UCRT
数据存储无数据库依赖，全部配置保存在一个 JSON 文件中
其他无（不联网验证、不读写数据库）
第三章 · 部署安装

部署安装

  1. 确认前置

    确认服务器已安装 Ark Server API 3.5 或更高版本（即服务器目录 ShooterGame\Binaries\Win64\ArkApi 已存在且正常运行）→ 没有安装请先安装 Ark Server API。

  2. 创建插件目录

    进入 ShooterGame\Binaries\Win64\ArkApi\Plugins 目录 → 新建文件夹并命名为 RatesScheduler。

  3. 复制插件文件

    把 RatesScheduler.dll、PluginInfo.json、config.json 三个文件复制进刚建好的 RatesScheduler 文件夹。

  4. 重启服务器

    重启方舟服务器 → 服务器完全启动后插件自动加载。

  5. 验证安装

    查看服务器控制台 → 出现「先锋.倍率调整器(1.0)」启动横幅，随后出现一行「倍率排程: 周1 18:00~24:00, 检查间隔 60 秒」样式的摘要日志 → 安装成功。

  6. （可选）放入配置编辑器

    把 编辑器.exe 也复制进插件文件夹 → 以后双击它即可在网页里可视化修改配置，详见第四章「配置文件说明」。

升级版本：用新的 RatesScheduler.dll 覆盖旧文件后重启服务器即可。正常关服时，若倍率活动正在进行，插件会自动还原倍率与 MOTD，不会残留活动倍率。
第四章 · 配置详解

配置文件说明

全部功能通过一个 JSON 配置文件控制，位置固定在插件目录内：

ShooterGame\Binaries\Win64\ArkApi\Plugins\RatesScheduler\
├─ RatesScheduler.dll    ← 插件本体
├─ PluginInfo.json       ← 插件信息（勿改）
└─ config.json           ← 全部配置都在这里
JSON 里逗号、引号一个都不能少。建议优先使用自带的网页配置编辑器（把 编辑器.exe 放进插件目录后双击运行，自动打开浏览器编辑页面，保存即写回 config.json）；手动修改的话推荐用带 JSON 校验的编辑器（如 VS Code），改前先备份。改坏的后果与补救见第六章常见问题。

第四章 · 配置详解

排程结构与匹配规则

什么意思：排程 是配置的核心，决定"哪天的什么时间段开什么倍率"。它是一个对象，键为 "1"~"7"（星期几的专属排程，1=周一、7=周日）和 "*"（通用兜底）。

匹配规则（重要）：每天按当天星期取对应的键（周一取 "1"……周日取 "7"）：只要当天键存在就一定用它，即使它是停用或时间非法的，也不会回落到 "*"；当天键不存在时才使用 "*" 的通用排程；两者都没有则当天无活动。

"排程": {
  "1":  { "启用": true, "开启时间": "18:00", "结束时间": "24:00", "倍率": { ... } },
  "5":  { "启用": true, "开启时间": "20:00", "结束时间": "23:00", "倍率": { ... } },
  "*":  { "启用": false, "开启时间": "00:00", "结束时间": "00:00", "倍率": { ... } }
}

怎么修改：想给某天单独安排活动，就在 排程 里加该天的键；想给没单独安排的日子统一兜底，就配置 "*"。上面例子表示：周一 18:00~24:00 一场、周五 20:00~23:00 一场，其余天不安排（"*" 停用）。

所有时间均按北京时间（UTC+8）计算，与服务器系统的时区设置无关。每天 0 点跨天时自动重置当日状态，前一天没结束的活动会自动收尾。
第四章 · 配置详解

排程条目：启用与时间

什么意思：每个排程键下是一个条目对象，启用 控制这条排程是否生效，开启时间/结束时间 定义活动时间窗。

兜底值：启用 false 开启时间 "00:00" 结束时间 "00:00"（条目里没写的键按兜底值处理）

"1": {
  "启用": true,
  "开启时间": "18:00",
  "结束时间": "24:00",
  "倍率": { ... }
}

怎么修改：启用 只能写 true/false；时间格式必须是 HH:MM（24 小时制），且必须开启时间 < 结束时间、不允许跨零点（不能 23:00 开、01:00 收），结束时间最大可以写 "24:00"（表示当天 24 点即零点收）。时间写非法的条目不会生效，服务器控制台会输出警告日志提示是哪个条目。

想临时停掉某一天的活动：把那天的 启用 改为 false 后 Reload 即可——因为当天键仍然存在，不会回落到 "*" 的兜底排程。
第四章 · 配置详解

倍率项配置（16 项）

什么意思：条目里的 倍率 对象控制活动期间修改哪些游戏倍率，共 16 项可选。倍率是"乘算"语义：实际倍率 = 服务器平时值 × 配置值——你服务器原本配置的数值不受破坏，活动结束自动恢复平时值。

兜底值：每项兜底都是 0，表示不修改该项（活动期间保持服务器平时值）；填负数按 0 处理并记警告日志。

"倍率": {
  "全局经验倍率": 2.0,
  "驯服速度倍率": 2.0,
  "采集数量倍率": 2.0,
  "留痕间隔倍率": 0.5,
  "资源刷新倍率": 1.0
}

怎么修改：上面例子表示活动期间经验/驯服/采集变为平时的 2 倍，留痕间隔缩短为平时的一半（要照顾幼崽更勤），资源刷新与平时相同。各项含义：

倍率键作用说明
全局经验倍率经验获取速度
驯服速度倍率驯服进度增长速度
采集数量倍率砍树、采石等获得的数量
资源血量倍率资源点的血量，越高单次采集产出越多
制作经验倍率制作物品获得的经验
钓鱼品质倍率钓鱼获得的奖励品质
光柱品质倍率补给箱/光柱的掉落品质
幼崽成长倍率幼崽成熟速度
孵蛋速度倍率蛋的孵化速度
留痕间隔倍率幼崽留痕需求的间隔，值越小需要照顾得越频繁
留痕加成倍率留痕完成获得的属性加成
交配间隔倍率恐龙交配冷却间隔，值越小交配越频繁
交配速度倍率交配过程的速度
产蛋间隔倍率母龙产蛋间隔，值越小产蛋越频繁
伴侣加成倍率伴侣关系带来的加成效果
资源刷新倍率资源重生周期，值越小刷新越快
倍率数值是乘数不是最终值：填 2 是在服务器平时值基础上翻倍；填 1 等于不变化；填 0 是完全不修改该项。活动结束会精确恢复到活动前的数值，不会破坏你 ini 里的原始配置。

命令段配置（命令改名）

什么意思：命令 段可以自定义三个聊天命令的触发文本（改名）。改完执行 RatesScheduler.Reload 后，旧命令文本自动注销、新命令文本立即生效。

兜底值：不配置时使用下表默认文本。

"命令": {
  "玩家命令": {
    "今日倍率": "/今日倍率"
  },
  "服主命令": {
    "重置倍率": "/重置倍率",
    "开启倍率": "/开启倍率"
  }
}
配置键兜底值说明
命令.玩家命令.今日倍率"/今日倍率"玩家查询命令的触发文本，所有玩家可用
命令.服主命令.重置倍率"/重置倍率"还原倍率命令的触发文本，仅管理员可用
命令.服主命令.开启倍率"/开启倍率"手动开启命令的触发文本，仅管理员可用

第四章 · 配置详解

通用段与控制台编码

通用.检查间隔秒

什么意思：插件每隔多少秒检查一次"该不该开/收活动"。到点精度取决于这个间隔——间隔 60 秒时，活动开启最多有 60 秒内的误差。

兜底值：60（不配置或超出范围 1~86400 时按 60 处理）

"通用": {
  "检查间隔秒": 60
}

怎么修改：想活动开启更准时就调小（如 30、10）；检查本身开销极小，按默认 60 用也完全没问题。

ConsoleEncoding

什么意思：插件往服务器控制台输出中文日志时的编码。不同版本 ArkApi 的控制台编码不同（3.54 为 GBK、3.55 为 UTF-8），设错会看到中文乱码。

兜底值："auto"（自动探测，推荐保持）

"ConsoleEncoding": "auto"

怎么修改：可选 "auto"（按控制台自动探测）、"gbk"/"ansi"（强制 GBK）、"utf8"/"utf-8"（强制 UTF-8）；写别的值视为非法，自动回落 auto 并在控制台输出提示。改完 Reload 即生效。

本章所有配置的生效方式：改完 config.json 后，在服务器控制台或 RCON 执行 RatesScheduler.Reload 即时生效，无需重启服务器；直接重启服务器当然也会加载新配置。热重载时若活动正在进行且时间窗仍有效，新倍率立即套用，不会重复发开启通知。
第五章 · 命令用法详解

命令总表与改名

聊天命令在游戏内聊天框输入；控制台/RCON 命令在服务器控制台或 RCON 工具输入。三个聊天命令的触发文本都可以在"命令"段改名。

命令权限作用改名配置键

第六章 · 常见问题

常见问题

改完配置怎么生效？必须重启服务器吗？
不用重启。在服务器控制台或 RCON 执行 RatesScheduler.Reload 即时生效；改命令文本、倍率、时间窗都支持热重载。重启服务器当然也会加载新配置。
Reload 提示 Failed to reload config 怎么办？
先试这个：说明 config.json 有 JSON 语法错误（最常见是多了/少了逗号、引号写成了中文引号）。用自带编辑器重新保存一次，或把文件粘到带 JSON 校验的编辑器里看报错行。重载失败不影响运行——插件会继续用上一次成功的配置。
排程配置了但活动没按时开？
依次检查：① 条目里「启用」是否为 true；② 时间是否满足「开启时间 < 结束时间」且不跨零点（结束最大 24:00）；③ 当天是否命中了专属键——周一~周日的键只要存在就一定用它（停用也不回落到 "*"），想用兜底排程就删掉当天的键；④「检查间隔秒」是否被改得过大。
倍率填 2 是变成"2 倍率"吗？
不是。倍率是乘算：实际值 = 服务器平时值 × 配置值。填 2 是在平时基础上翻倍，填 1 等于不变，填 0 是完全不修改该项。活动结束自动恢复到活动前的精确数值。
服务器控制台中文日志乱码？
把 ConsoleEncoding 按服务器控制台实际编码改成 "gbk" 或 "utf8" 后 Reload。多数情况保持 "auto" 自动探测即可。
改了命令文本，旧命令还能用吗？
Reload 后插件会自动按旧文本注销、按新文本重新挂载命令，不会出现新旧命令并存或旧命令残留。
怎么临时停掉某一天的活动？
把那天的排程键里「启用」改为 false 后 Reload。注意：当天键存在时不会回落到 "*"，所以这是"只停这一天"；想全停就把所有键（含 "*"）都停用。
卸载插件后活动倍率会残留吗？
不会。插件卸载（含正常关服）时若活动正在进行，会自动还原 16 项倍率并换回常规 MOTD。若服务器异常崩溃，重启后服务器会按自己的 ini 配置初始化倍率，也不会残留。
