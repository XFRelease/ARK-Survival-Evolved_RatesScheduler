配置一次时间表，每天到点自动开、到点自动收，全服通知、MOTD 同步换——你睡觉，它营业。

01 · 软件定位

软件定位

手动办一场倍率活动有多累？定闹钟、掐着点改服务器配置再重启、活动完了还得记得改回去——忘关一次，双倍经验挂一整周；不开活动，玩家又在群里天天问"今晚几点开"。活动越勤快，你被拴在服务器前的时间越长。

倍率调整器（RatesScheduler）是方舟生存进化的服务端插件，专为"自动经营倍率活动"而生：你把周一到周日每天的活动时间和倍率一次配好，它就每天到点自动开活动、到点自动收倍率，屏幕大字 + 聊天广播全服通知，连服务器 MOTD 都自动换好。玩家用一条命令自助查询，你只管收人气。配置一次，天天营业。

03 · 重点功能

定时倍率调度 核心

什么功能：按时间表在指定时间窗自动修改服务器的游戏倍率，时间一到自动应用、时间一到自动还原。

什么作用：晚间场、周末场、节假日专场全部自动运转，活动节奏稳定，玩家养成到点上线抢活动的习惯。

给你的好处：没有它，你办活动要掐着表改 ini、重启服务器、半夜定闹钟收倍率——忘收一次就是一整周双倍。有了它，16 项倍率（经验、驯服、采集、孵化、留痕、交配、产蛋、资源刷新等）在平时值基础上乘算生效，活动结束精确恢复到你 ini 里的原始数值，服务器配置零破坏。你配置一次，它天天营业。

03 · 重点功能

按星期排程 + 通配兜底 核心

什么功能：周一到周日每天一条专属排程，各配各的时间与倍率；再配一条 "*" 通配排程兜底所有没单独安排的日子。

什么作用：工作日晚上 2 小时轻量场、周末全天豪华场、平日通配小福利——一张时间表管一周。

给你的好处：不用每天手动开关：周末想开猛一点就给周六周日单独配，平时用 "*" 兜底小倍率维持人气。想临时停掉某一天，把那天"启用"改成 false 就行，互不影响其他天。所有时间按北京时间计算，与你服务器系统时区无关，跨服、海外服都不用换算。

03 · 重点功能

全服通知 + 预告提醒 人气担当

什么功能：活动开启/结束瞬间，屏幕中央大字 + 聊天栏彩色广播同时通知全服；可配置提前 N 分钟预告、结束前 N 分钟提醒，文案和颜色全部自定义。

什么作用：玩家再也不会"活动开了不知道、快结束了才发现"——预告一出全服集合，提醒一出疯狂收尾，活动参与感直接拉满。

给你的好处：以前你办活动得自己在群里喊话、在游戏里广播，半夜场还得定闹钟。现在通知完全自动：文案支持"{分钟}"占位自动替换倒计时，颜色用 RGBA 自定义，广播署名就是你的服务器名。一场活动的预热、开启、收尾提示，全自动安排得明明白白。

03 · 重点功能

MOTD 自动切换 门面担当

什么功能：活动开启时自动把服务器 MOTD（进入服务器欢迎信息）换成活动公告，活动结束自动换回常规欢迎语。

什么作用：每个新进服的玩家第一眼就知道"现在正在倍率活动"，进服即知情。

给你的好处：不用再手动改 MOTD 提醒活动——活动公告和活动本身同生同灭，永远不会出现"MOTD 还挂着上周活动"的尴尬。

03 · 重点功能

服主手动接管 灵活掌控

什么功能：管理员聊天命令 /开启倍率、/重置倍率，随时无视时间表手动开一场或提前收掉。

什么作用：直播福利、在线人数破百庆祝、临时活动说开就开。

给你的好处：自动排程是主力，手动接管是底牌——想加场就 /开启倍率 立即套用今日配置，想收场就 /重置倍率 秒回官方倍率；到下一个时间窗边界，自动调度无缝接管。命令文本还能自定义改名，配合你的服务器风格。

03 · 重点功能

网页配置编辑器 + 热重载 省心运维

什么功能：自带单文件网页编辑器：放进插件目录双击运行，浏览器里可视化编辑配置，保存即写回；配合控制台/RCON 一条 Reload 命令，配置秒级生效。

什么作用：改时间、改倍率、改文案全程不重启服务器，在线玩家无感知。

给你的好处：改配置不用挑深夜停服窗口：活动进行中改倍率立即套用新值，改命令文本自动换绑，JSON 写错了也只回一句失败提示、插件继续按旧配置跑——安全热更新，怎么折腾都不掉线。
